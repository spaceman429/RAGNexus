# offer 沟通、候选人淘汰标准化模板库

> 适用范围：全技术岗 HR 与用人部门  
> 版本：v1.0 | 使用说明：复制后替换 `【】` 内变量，通过公司邮箱发送

---

## 1. 使用原则

- 所有候选人沟通须通过 **公司招聘邮箱** 或 ATS 系统发送，保留记录。
- 禁止微信口头 Offer、禁止承诺未经审批的薪酬职级。
- 淘汰通知须在面试结果确定后 **3 个工作日** 内发出（候选人主动放弃除外）。

---

## 2. 面试通过 — 进入下一轮

**主题：** 【公司名称】技术岗面试进展 — 邀请参加下一轮面试

```
【候选人姓名】，您好：

感谢您参加我司【岗位名称】的【初试/复试】。

经面试官评估，您已进入下一轮面试安排。HR 将在 1~2 个工作日内与您确认具体时间。

如有疑问，请回复本邮件或联系【HR 姓名】【电话/邮箱】。

祝好，
【公司名称】人力资源部
```

---

## 3. 面试通过 — 进入 HR 面 / 背调

**主题：** 【公司名称】【岗位名称】— 后续安排通知

```
【候选人姓名】，您好：

恭喜您通过【岗位名称】的技术面试环节。

下一步安排：
1. HR 综合面试，时间：【日期时间】，形式：【线上/线下】，链接/地址：【】
2. 面试通过后将启动背景调查，请提前准备背调授权材料。

请确认是否可按时参加，或提出可面试的时间段。

【HR 姓名】
```

---

## 4. Offer 发放

**主题：** 【公司名称】录用通知书 — 【岗位名称】

```
【候选人姓名】，您好：

很高兴通知您，经综合评估，我司决定录用您为【部门名称】【岗位名称】，职级【P*】。

主要条款摘要：
- 入职日期：【YYYY-MM-DD】
- 工作地点：【城市/办公地址】
- 薪酬结构：基本工资【】元/月，绩效【】，年终奖按公司政策
- 试用期：【3/6】个月，试用期薪酬【同正式/90%】

完整录用通知书见附件 PDF，请于【日期】前签署并回传。

如有疑问请致电【HR 姓名】【电话】。期待您的加入！

【公司名称】人力资源部
```

## 5. 标准化淘汰通知

### 5.1 简历初筛未通过

**主题：** 【公司名称】应聘反馈 — 【岗位名称】

```
【候选人姓名】，您好：

感谢您对【公司名称】【岗位名称】的关注与投递。

经评估，您目前的经历与该岗位需求存在一定差距，本次暂不安排面试。
您的简历已录入人才库，如有合适岗位我们会主动与您联系。

祝您求职顺利！
【公司名称】人力资源部
```

### 5.2 面试未通过（通用）

**主题：** 【公司名称】面试结果反馈 — 【岗位名称】

```
【候选人姓名】，您好：

感谢您抽出时间参加我司【岗位名称】的面试。

经综合评估，本次未能与您达成合作。主要考量为【与岗位技能匹配度/项目经验方向/职级定位等，选 1~2 项客观描述，避免人身评价】。

再次感谢您的诚意，祝您早日找到心仪的工作。

【HR 姓名】
```

### 5.3 背调未通过（谨慎使用）

**主题：** 【公司名称】录用进展说明

```
【候选人姓名】，您好：

关于【岗位名称】的录用事宜，经入职前核实流程，部分信息与申报情况存在差异，我司无法继续推进录用。

如有疑问，请于 3 个工作日内联系【HR 姓名】【邮箱】。

【公司名称】人力资源部
```

---

## 6. 候选人放弃 / 拒 Offer 归档

HR 在 ATS 标注原因：薪酬 / 地点 / 其他 Offer / 个人原因 / 未说明。供渠道 ROI 与薪酬带宽分析使用。

---

## 7. 禁止使用的表述

- 「你不够优秀」「我们找了更好的」等人身评价
- 「年纪太大了」「女生不适合」等歧视性语言
- 透露其他候选人信息或内部编制细节
