# 面试官行为规范、保密与面试红线

> 适用范围：全体参与技术面试的员工  
> 版本：v1.0 | 归口：人力资源部

---

## 1. 面试官资质

- 须为公司正式员工，在岗满 **6 个月**。
- 职级不低于候选人目标职级，或经部门负责人授权。
- 入职前须阅读本规范并签署《面试官承诺书》。

---

## 2. 行为规范

### 2.1 面试前

- 提前 **15 分钟** 阅读候选人简历与初筛备注。
- 确认面试会议室 / 线上链接、设备正常。
- 不得向无关人员透露候选人姓名、当前公司、薪酬等隐私。

### 2.2 面试中

| 要求 | 说明 |
|------|------|
| 准时 | 迟到超过 10 分钟须道歉并说明，且通知 HR 协调 |
| 尊重 | 禁止嘲讽、打断、贬低候选人经历 |
| 专注 | 不使用手机处理私事，不做与面试无关操作 |
| 记录 | 关键问答与评价当场或面试后 2h 内录入 ATS |
| 时长 | 技术面试 45~60 分钟，含 5 分钟候选人提问 |

### 2.3 面试后

- **24 小时内** 提交结构化面试评价，不得仅给「感觉不错」等模糊结论。
- 不得私下联系候选人讨论 Offer、薪酬（统一由 HR 对接）。
- 面试题、候选人答案不得外传或发布至社交媒体。

---

## 3. 保密义务

面试官对以下信息负有保密义务，离职后仍有效：

1. 面试题库、编程题、系统设计题及评分标准
2. 候选人简历、作品集、薪酬期望、离职原因
3. 公司内部组织架构、项目代号、未公开技术方案
4. 其他候选人的面试表现与录用结论

违反保密义务者，按《员工违纪处理办法》追责。

---

## 4. 面试红线（禁止行为）

以下行为 **一律禁止**，触犯者取消面试官资格，情节严重者追究法律责任：

| 红线 | 示例 |
|------|------|
| 歧视性提问 | 询问婚育计划、宗教信仰、籍贯歧视、性别偏见 |
| 利诱胁迫 | 「来我们公司就帮你解决户口」「不接受加班就别来」 |
| 套取机密 | 要求候选人提供前雇主源码、客户名单、商业数据 |
| 泄题 | 将本次面试题告知其他候选人或同事 |
| 利益冲突 | 隐瞒与候选人的亲属、投资、竞业关系 |
| 虚假承诺 | 口头承诺编制、职级、薪酬未经审批的内容 |
| 私下交易 | 收受候选人礼品、礼金、招待 |

---

## 5. 合规提问参考

**可以问：**

- 项目技术细节、难点与个人贡献
- 职业规划、技术学习兴趣
- 可入职时间、工作地意愿
- 期望薪酬范围（建议由 HR 统一询问）

**不建议问：**

- 是否已婚已育、何时生育
- 详细家庭财务状况
- 与前雇主劳动纠纷细节（可问离职原因，但不得追问隐私）

---

## 6. 投诉与申诉

候选人可通过招聘官网、HR 邮箱投诉面试官不当行为。HR 须在 **3 个工作日** 内调查并反馈。查实违规的，按红线处理。
